SOS: Save Our Stereos

SOS: Save Our Stereos is a 2d rhythm game centered around its unique controller interactions which involve pointing a torch towards an array of 5 light sensors to hit the notes coming towards the player in time with the music. The player earns points for each note hit and gradually gains a point multiplier for hitting notes consecutively.

View on Github

I connected 5 light dependent resistors to an arduino microcontroller which consistently measures their values and checks whether they're above a threshold value upon which the arduino sends an input to the respective target in the game. I housed the light dependent resistors in individual hoods that keep them shaded so that they only reach the threshold value when exposed to direct light rather than in passive room light.

I 3d printed a housing for the system that mounts around a computer monitor. It has 5 antenna-like targets containing the light dependent resistors far enough away from each other to avoid accidental inputs which attach by wire to a small box containing the microcontroller. It is also extensible so that it fits a range of laptop and monitor screen sizes.

This project was demoed at the Falmouth University Game Expo 2024.
