Lego Sorting Assistant

This is a tool I made to help streamline the process of organising my childhood lego back into their original sets so I could sell them. It's used to keep track of all the parts and minifigures in a set whilst I'm rooting through a big box of jumbled up pieces so I know what parts I'm looking for and can keep track of what parts I've already found.

View on Github (In Progress)

I used Rebrickable's Lego Catalog API to search for sets, get part and minifigure data for generating the checklist, and get general data about the set like the year it was made and how many parts it contains.

I created a saving and loading system which converts the checklist data to json, including images to avoid unnecessary API calls, and converts the json back to a checklist. The checklist saves every time an element gets changed and occurs before the UI updates to ensure the displayed and saved data stay consistent.
