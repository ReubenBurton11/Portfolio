Music Visualiser

A website intended for use as a dynamic desktop wallpaper, featuring a well-equipped music player as well as a background graphic visualisation which reacts to the current music. The music player includes a play/pause toggle, skipping, looping, scrubbing, queuing, and volume control functions.

I created a file upload system using a mix of javascript and vue components that allows the user to either click to upload or drag and drop an mp3 file that gets added to the back of a queue of files waiting to be played. It allows for the removal of files from any point in the queue with the following files moving up the queue to compensate.

I used academic research to inform the visualisation so it would elicit a more connected experience to the music. The visualisation's features are intuitive consisting of a waveform that is curved clockwise around a circle, it's amplitude represents the music's volume and it's colour relates to volume and pitch, with the saturation changing with volume and the hue changing with pitch.
