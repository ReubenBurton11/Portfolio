Game Jams

Cosmic Clinic

A game I worked on with a small team for the global game jam 2025. Players take on the role of an interdimensional plague doctor, who happens to be a fish, and must treat as many patients as possible by popping their pus bubbles with the appropriate tools before they succumb to their disease.

View on Itch.io

For this project, I handled randomly spawning pus bubbles on the surface of patients bodies and created the system for certain tools only popping certain bubbles. I also cleaned up the other programmers' code so that the parts programmed in C++ and Blueprints worked together as well as sorting out the version control throughout so that most changes were successfully integrated without overriding core features.

Fish Finger Factory

A game I worked on solo for the GMTK game jam 2024. A simplistic top-down factory simulation game in which the player takes control of an empty fish finger factory and must build it into a fish finger empire.

View on Itch.io

I created a grid based building system which allows for building and destroying 6 types of factory pieces tied to buying and selling mechanics. I also created a system for objects (fish) to travel along conveyor belts, entering machines and being output as different object types with different sell values.
